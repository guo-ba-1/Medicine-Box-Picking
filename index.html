使用说明

1 · 下载数据

每个数据集页都提供三种链接，按用途选择：

  • 原始文件（raw）：raw.githubusercontent.com/<user>/<repo>/<ref>/<path>，适合 pandas.read_csv、wget、curl 直接抓取。
  • CDN 加速（jsDelivr）：cdn.jsdelivr.net/gh/<user>/<repo>@<ref>/<path>，全球加速且带缓存，适合网页端读取。
  • GitHub 页面 / Release 附件：适合人工浏览与长期归档；打 tag 后链接永久不变。

2 · 让链接永久有效

main 分支上的内容会随提交变化。论文引用请使用 tag（版本号）而不是分支名，例如 @v1.2.0。 发版命令： 

git tag -a v1.2.0 -m "release v1.2.0"
git push origin v1.2.0

更正式的长期归档可以再把同一份数据上传到 Zenodo（GitHub 仓库打 tag 后自动获得 DOI），然后在数据集元数据里填入 doi 字段。

3 · 在文章中引用

打开任一数据集，点击「引用与链接」即可复制：

  • BibTeX（LaTeX / Overleaf）
  • APA 第 7 版（英文期刊常用）
  • GB/T 7714—2015（中文期刊与学位论文）
  • Markdown 行内引用（博客、README）
  • 数据可用性声明（Data Availability Statement）

4 · 发布你自己的站点

把本仓库推到自己的 GitHub 账号，执行仓库根目录的 scripts/publish.ps1，脚本会：

  1. 检测 git / gh 并引导登录；
  2. 创建远程仓库、提交并推送；
  3. 开启 GitHub Pages（Actions 构建）并打印最终网址。

详细步骤见仓库根目录的 README.md。
